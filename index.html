ABOUT THIS PROJECT

Project Guide

Moodify is a mood-based music recommendation prototype. Users select a mood and receive a curated set of song suggestions that fit that feeling.

1. Choose a mood

Select Happy, Sad, Relaxed or Angry from the mood cards.

2. Get recommendations

The app selects five songs from its built-in mood library.

3. Save favorites

Use the heart button to save songs in this browser.

This is a front-end demonstration. Recommendations come from a sample dataset; music playback and streaming require a licensed music service or API integration.

RECOMMENDATION LOGIC

How the Algorithm Works

  1. Input: The user selects one of the available moods.
  2. Matching: The selected mood is used as a key to find songs in the local recommendation dataset.
  3. Selection: Five matching songs are displayed with their artist and a short mood description.
  4. Personalization: Users can save preferred songs to browser storage for later access.
