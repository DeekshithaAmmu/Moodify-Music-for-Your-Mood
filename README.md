# Moodify – Music for Your Mood

A responsive, front-end mood-based music recommendation demo.

## Features
- Four mood categories: Happy, Sad, Relaxed and Angry
- Five sample song recommendations for each mood
- Surprise Me mood selection
- Save and remove favorite songs using browser local storage
- Project Guide and explanation of the recommendation logic
- Links to find songs on YouTube (no streaming API or copyrighted audio is bundled)

## Run locally
Open `index.html` in a modern web browser. No installation or build step is required.

## Deploy on Render
1. Upload this folder to a GitHub repository.
2. In Render, choose **New + → Static Site** and connect the repository.
3. Set the **Publish Directory** to `.` (a single dot). No build command is needed.
4. Deploy.

## Important
This is a newly written implementation based on the visible Moodify interface and feature descriptions shared in the conversation. It is not the original source code extracted from the AI Studio preview. Song data is illustrative; music links open YouTube search results. A production app would need verified music metadata and any required API credentials.
